## Project description

BelowTrace is a free, open-source web tool for Detroit households facing a basement sewage backup or private sewer concern. A resident enters an address, sees the relevant public infrastructure and program records, then starts a case that keeps the DWSD service-request number, observed facts, evidence, deadlines, and the next official question. The printable case file can be handed to DWSD, a plumber, an insurer, or a repair program. The product is deliberately cautious: public records never become a guessed private pipe, a responsibility ruling, or a claim decision.

Our Sept. 18 City data snapshot contains 14,115 Detroit 311 water-in-basement requests since January 2023. These are requests, not unique households or confirmed causes. The first pilot will test whether residents can find a safe next action, preserve a service-request number, and correctly understand what still needs to be verified.
