# BelowTrace — 需求验证记录（2026-09-17/18）

## 结论

**做：** 地下室返水/下水管坏了、修不起的 Detroit 房主，输入地址 → 知道谁的责任、哪个免费或补助项目可能轮到自己、按什么顺序做、有哪些截止日期、自家小巷市政下水道有哪些公开记录。

**不做：**
- "推断管线走向"当核心：Detroit 私人管默认走后院接小巷主管（DWSD 官方示意图），记录解决不了定位，定位只能靠现场摄像头/探头。
- 社区级地下室进水风险地图：已有 basementriskcheck.com。
- PSRP 社区范围查询本身：市政已有 Eligibility Tool（只判断是否在 97 个社区内）。
